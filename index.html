🐧 O que é GNU/Linux?

GNU/Linux é um sistema operacional formado principalmente pela combinação de duas partes:

GNU → fornece várias ferramentas e programas básicos do sistema.
Linux → é o kernel (núcleo) do sistema operacional, responsável por controlar o hardware e permitir que os programas se comuniquem com ele.

De forma simples:

GNU + Linux = um sistema operacional completo

🔹O que é o Linux?

O Linux propriamente dito é apenas o kernel. Ele é responsável por coisas como:

• 🧠 Gerenciar memória RAM
• ⚙️ Controlar o processador
• 💾 Gerenciar arquivos e armazenamento
• 🔌 Controlar dispositivos e periféricos
• 🌐 Gerenciar redes
• 👥 Controlar usuários e permissões
• 🖥️ Permitir que programas utilizem o hardware

Por exemplo, quando você digita ls e aperta o botão enter no terminal, o comando conversa com o sistema operacional, que utiliza o kernel Linux para acessar o armazenamento e descobrir quais arquivos existem.

🔹E o que é GNU?

GNU é um projeto iniciado por Richard Stallman em 1983 com o objetivo de criar um sistema operacional livre.

O projeto GNU fornece muitas ferramentas utilizadas em sistemas Linux, como:
bash, gcc, ls, cp, mv, rm, grep, cat

Por isso, tecnicamente, muitos sistemas que chamamos simplesmente de "Linux" são GNU/Linux.
